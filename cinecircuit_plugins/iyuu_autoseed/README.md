# IYUU 辅种

要求 CineCircuit v1.3.5 或更新版本，以及有效 IYUU Token 和已配置的 PT 站点。自动辅种默认关闭。Token 由宿主加密保存，插件不接收站点 Cookie、Passkey 或下载器密码。

选择来源下载器，可设置独立目标下载器、站点、体积、排除标签和目录。带“刷流”标签的来源始终排除。插件批量查询同源种子，使用 CC 主项目的站点下载能力获取种子；只有候选文件的相对路径和大小与来源完全一致才暂停提交。两端必须访问同一份文件，插件不会复制、移动或重命名数据。

默认先校验再启动；qB 可选择跳过校验，并独立决定是否启动。失败会记录可重试缓存，404/410 保留至清除缓存；成功缓存和下载器任务检查防止重复提交。清除缓存与立即执行开关只消费一次，校验队列可在重启后继续处理。

统计页面使用 CC 现有组件。未配置真实 Token 时仅能验证模拟协议、任务生命周期和页面，不能代替真实 IYUU 账号联调。上游参考见 [SOURCES.md](SOURCES.md)。
