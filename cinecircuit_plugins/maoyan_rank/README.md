# 猫眼榜追更

## 支持功能

- 跟踪电影票房、电视剧、网剧、综艺及网络电影榜单。
- 选择榜单处理数量，支持各视频平台热播榜订阅。
- 定时匹配榜单作品并添加订阅，记录处理历史。

## 使用方法

1. 在主程序中配置订阅使用的站点、下载器和筛选规则。
2. 安装并启用插件，选择榜单类型和处理数量。
3. 按需开启全网或指定平台的热播榜，设置执行周期。
4. 保存配置后，通过插件记录与订阅列表查看结果。

## 注意事项

- 榜单内容和访问情况会随来源变化，匹配失败时查看具体记录。
- 建议先选择少量榜单和较小数量，确认订阅效果后再扩大范围。
- 清理历史后，下一次执行会重新评估榜单作品。
