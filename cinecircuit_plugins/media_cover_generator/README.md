# 媒体库视觉工坊

## 支持功能

- 为媒体服务器中的媒体库生成并上传静态或动态封面。
- 提供单图、多图拼接、海报画廊、动态轮播等多种样式。
- 设置中英文标题、字体、字号、分辨率、背景与文字效果。
- 动态封面支持 WebP、APNG、GIF，可设置时长和帧率。
- 支持预览、保存最近封面、跳过未变化内容和缓存清理。
- 支持定时执行，以及整理、同步或刮削完成后触发。

## 使用方法

1. 在主程序中配置媒体服务器，确认媒体库已有可用海报或背景图。
2. 安装并启用插件，选择服务器和需要生成封面的媒体库。
3. 选择封面样式，设置标题、字体及尺寸；动态样式再设置动画参数。
4. 先使用预览模式检查效果，确认后执行上传。
5. 需要自动更新时设置周期或触发事件，并按需保留最近生成的封面。

## 注意事项

- 上传封面会更新所选媒体库的封面图片，请先确认目标媒体库。
- 动态封面的播放效果取决于媒体服务器及客户端支持。
- 较高分辨率、帧率和较长动画会增加生成时间、内存占用和文件大小。
- 生成效果受可用图片数量、尺寸及质量影响。
