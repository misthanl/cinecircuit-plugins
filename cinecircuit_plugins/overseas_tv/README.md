# TMDB 剧集追踪

通过主程序配置的 TMDB 数据源发现 Netflix、HBO、Disney+、Apple TV、Prime Video、Hulu 的近期新剧和新季，按 TMDB ID＋季号创建订阅。平台指 TMDB 电视网归属，不保证独家原创，不是某地区的完整平台片库。

- 设置页沿用猫眼的两列布局和 SchemaFields；统计页沿用猫眼的统计卡片、处理明细、重试筛选、海报历史及分页。
- 默认每 6 小时执行，最近 30 天到未来 14 天，每个平台最多检查 10 部候选，每轮最多新增 10 季。
- 默认不包括动画、纪录片、真人秀／脱口秀；特别篇不订阅。国家、语言可选。评分不足的人数阈值与最低评分分别设置。
- 新季按季首播日期判断，不会因剧集首次播出于多年前而漏掉新季。日期缺失的季暂不订阅，下一轮重查。
- 热门模式是时间范围内的 TMDB 热度排序，不是 Netflix/HBO/Disney+ 官方热榜；候选数量有上限，不能承诺涵盖全片库。
- 已订阅、整季已入库会跳过；媒体库或季集信息无法确认时暂缓。单集存在不等于整季完成。
- 每轮数量限制只统计成功新增，超出部分不记已处理，下轮仍可检查。
- 使用现有扩展服务执行；没有浏览器、没有常驻定时器、没有无界内存缓存。任务由主程序统一调度，手动成功后的退避解除沿用主程序行为。

## 兼容性

需要支持 `MediaDiscoveryGateway.supports_catalog_filters` 的主程序，否则明确报错，绝不静默忽略平台筛选而误订阅。无需另外填写 TMDB 密钥。

首发版本 1.0.0。开发前已核对远端插件目录提交 a236f534ec33081956922b7df1417841d6222ee5，无同名插件。NAS 只读验证确认平台 ID：Netflix 213、HBO 49、Disney+ 2739。

包含类型使用现有多选组件；旧动画／纪录片／真人秀开关自动迁移，旧预览和排除 ID 配置不再生效。已显式保存的平台数量保留，新配置默认 10。
