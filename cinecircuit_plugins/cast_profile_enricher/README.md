# 演职员资料完善

## 支持功能

- 补充人物中文姓名、简介、角色信息与头像。
- 结合 TMDB、豆瓣资料完善媒体服务器中的人物信息。
- 按全部人物、资料或角色缺失、姓名未中文化、角色未中文化等范围处理。
- 支持定时执行，以及整理完成、同步完成或刮削完成后触发。
- 保存处理进度，查看结果统计，并在后续执行中继续处理未完成项目。

## 使用方法

1. 在主程序中配置媒体服务器，确认可读取和更新媒体信息。
2. 安装并启用插件，选择媒体服务器和处理范围。
3. 按需启用简介更新，设置定时周期或触发事件及延迟。
4. 保存后查看执行记录，确认人物资料和角色更新结果。
5. 需要清理无法完善的人物时，仔细确认范围后再开启相应选项。

## 注意事项

- 完善效果取决于媒体身份匹配以及来源提供的中文资料和图片。
- 人物资料可被多个作品共用，角色信息按作品分别处理。
- 网络异常、来源限制或写入失败时，查看记录中的失败原因后重试。
- “移除无法完善的人物”会修改作品的演职员列表，默认关闭，启用前请核对用途。
