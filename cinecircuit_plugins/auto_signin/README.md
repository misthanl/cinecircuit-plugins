# 站点签到管理

## 支持功能

- 自动登录、签到已配置的 PT 站点。
- 按执行周期运行，支持选择登录站点和签到站点。
- 设置并发数量、重试关键词和结果通知，查看执行记录。

## 使用方法

1. 在主程序中添加站点，确认账号和 Cookie 有效。
2. 安装并启用插件，选择需要登录、签到的站点。
3. 设置执行周期和并发数量，按需开启结果通知后保存。
4. 在插件执行记录中查看各站点的结果，按提示处理失败项。

## 注意事项

- 各站点的签到规则和频率限制不同，建议设置适当的执行间隔。
- Cookie 失效、验证码或站点维护可能导致失败，处理后再执行。
- 清理缓存选项会影响下一次执行使用的签到缓存。
