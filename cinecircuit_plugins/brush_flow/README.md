# 站点刷流

## 支持功能

- 根据站点和任务规则筛选资源并提交下载。
- 为任务选择站点、下载器，设置全局最大任务数。
- 按周期执行任务，按规则清理种子，发送结果通知。

## 使用方法

1. 在主程序中配置站点与下载器，确认连接正常。
2. 安装并启用插件，添加刷流任务，选择站点、下载器及筛选规则。
3. 设置执行周期和最大任务数，保存配置。
4. 需要自动清理时，开启清理规则并核对删除条件。
5. 通过任务和下载器记录查看下载、做种及清理结果。

## 注意事项

- 下载、做种和清理应遵守站点规则，留意 H&R、保种时间及分享率要求。
- 根据磁盘空间和网络带宽设置任务数量。
- 允许删除数据文件后，符合条件的清理操作会删除对应文件，请先核对规则。

## 任务通知

通知仅由每个任务的“发送通知”开关控制，无全局通知开关。
发送进种结果、执行失败，以及实际暂停或删除种子的清理结果。
定时执行达到同一数量或体积上限时，在通知成功送达后不重复提醒；
恢复进种后再次达到上限会重新提醒，手动执行每次显示上限结果通知。
任务停用、等待周期、进种时间外和没有实际操作的清理检查不发送通知。
主程序通知渠道需要允许“插件”类型，并授予插件通知权限。
按任务控制通知需配套支持 `notification_control` 的主程序版本。
