# 字幕管理助手

## 支持功能

- 浏览已登记的媒体文件，查看和管理本地字幕。
- 搜索在线字幕，预览、下载、手动上传和调整字幕时间轴。
- 支持 SubHD、字幕库、ASSRT、OpenSubtitles、SubDL、射手影音、迅雷看看。
- 按语言、格式和匹配程度选择字幕，支持最佳字幕、全部中文字幕和全部字幕模式。
- 支持自动下载时将繁体中文字幕转换为简体。
- 支持整理完成、同步完成或刮削完成后自动处理对应媒体。

## 使用方法

1. 安装并启用插件，打开“开启侧边菜单”以使用字幕管理工作台。
2. 在“在线字幕源”中选择来源，按来源要求填写 API Key、账号或接口地址。
3. 从工作台选择媒体，进入“在线字幕”搜索，预览后下载合适的字幕。
4. 上传自己的字幕时选择文件及语言；自动识别不确定时手动指定语言。
5. 需要自动处理时，在基础设置选择触发事件，设置语言、格式优先级和最低匹配分。
6. 按需开启繁转简、同名覆盖和结果通知，保存配置。

## 注意事项

- 媒体及字幕保存目录需要主程序能够访问，并具备相应读写权限。
- 射手影音、迅雷看看按视频片段匹配；STRM 指向的视频需要能够解析并支持 HTTP Range 读取。
- ASSRT、OpenSubtitles、SubDL 的调用受账号权限和接口配额影响；网页来源遇到登录或验证码时，按页面提示处理。
- 支持 SRT、ASS、SSA、VTT、SBV、部分文本 SUB 和 ZIP；SBV 与支持的文本 SUB 会转换为 SRT。MicroDVD 转换需要文件声明帧率。
- 单个字幕上限 10 MiB，ZIP 最多 64 个条目。RAR、7z 和图片字幕请先自行转换或解包为支持的格式。
- 默认保留已有同名字幕，开启覆盖前请确认需要替换。
- 繁转简用于自动下载保存的中文字幕；时间轴、语言识别及来源匹配结果建议通过预览核对。
