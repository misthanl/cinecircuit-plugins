# 字幕管理助手

事件触发仅处理事件 `items` 携带的媒体路径，不回退扫描整理历史或全库。未选择事件时不执行自动任务。

基础设置的“开启侧边菜单”控制字幕管理工作台入口，默认开启；插件本身未启用时不显示。关闭入口不停止事件处理，也不作为页面访问权限。此设置依赖宿主通用 `navigation.visibility_config_key` 支持，首次使用需要更新宿主，不能只替换插件包。旧配置缺少该值时采用开关默认值。

自动处理依次执行：搜索候选、获取下载地址、下载及 ZIP 解包、校验片名/年份/季集与字幕时间轴、通过宿主 `media_files.write_subtitle` 保存。默认不覆盖同名字幕；多字幕模式按语言和格式去重，避免互相覆盖。事件必须指向宿主可访问的媒体文件；不可访问的网盘路径不会写入其他位置。

下载源支持：

- SubDL：官方 v1 API（https://subdl.com/api-doc），在账户面板申请 API Key，配置加密保存。按 TMDB/IMDb ID 或片名查询，支持语言及季集筛选；下载使用官方公开地址，不附带密钥。
- 射手影音：使用 https://www.shooter.cn/api/subapi.php，按视频 4 个位置各 4 KiB 的 MD5 组合查询。用户参考客户端：https://github.com/ngjaying/nw-shooter 。
- 迅雷看看：使用 http://sub.xmp.sandai.net:8000/subxl/{CID}.json，CID 为视频 3 个位置各 20 KiB 的 SHA-1。协议参考：https://github.com/ChineseSubFinder/ChineseSubFinder/blob/master/pkg/logic/sub_supplier/xunlei/xunlei.go 。

射手、迅雷通过宿主通用 `media_files.read_samples` 读取实际视频的少量片段，不上传视频，也不下载整部视频。要求同时更新主程序；支持已配置目录中的视频原文件及 STRM。STRM 通过主程序解析为视频，使用 HTTP Range 读取少量字节；已登记的云盘 STRM 由主程序存储服务解析，插件不接触云盘凭据或签名地址。不支持 Range、返回页面/播放列表、文件大小或版本变化时跳过该源，不回退下载整部视频。结果按文件哈希匹配，仍拒绝文件名明确标为其他集数的字幕；同一搜索中的多个片名不会重复查询同一文件。已有字幕源选择保持不变，需要在在线字幕源设置中勾选新来源。


- ASSRT：使用搜索 ID 查询详情及文件列表。协议依据 https://assrt.net/api/doc 。
- OpenSubtitles：使用搜索结果的 `files[].file_id` 请求 `/download`，支持已配置账号登录。协议依据 https://github.com/opensubtitles/mcp.opensubtitles.com 。
- SubHD、字幕库：解析页面明确提供的公开字幕或 ZIP 链接。验证码、登录墙及没有文件链接的页面会失败，不绕过网站验证。

安全限制：单文件 10 MiB，下载/解包总量有界，ZIP 最多 64 个条目；不向磁盘解压、不接受路径穿越或加密 ZIP；拒绝 HTML、无有效时间轴的文件以及内部网络下载地址。支持 SRT、ASS、SSA、VTT/WebVTT、SBV、文本 SUB 和 ZIP，RAR/7z 不自动解包。

WebVTT 统一保存为 `.vtt`；SBV、SubViewer 2 文本 SUB 转为 SRT；MicroDVD 仅在首行声明有效帧率时转为 SRT，支持 `|` 换行，暂不接受格式控制标签。不猜帧率，不处理图片 SUB/IDX、其他 SUB 方言；失败不会写入部分文件，也不阻止同 ZIP 内其他有效字幕。新格式自动下载和手动上传共用插件内转换，宿主仍接收已有支持格式。

自动选择默认按简体中英双语、繁体中英双语、简体中文、繁体中文、未区分简繁的中文、英语排序，再比较格式。旧默认优先级自动映射到新默认，自定义顺序保留。最多下载 20 个候选，按实际正文比较后保存，优选缓冲上限 64 MiB，因此较原来的首个成功即停止会产生更多下载。双语基于中文正文与英文短语判断，排除时间轴、ASS 样式头和控制标签；属于启发式识别，不保证所有极短文本准确。启用繁转简后按转换后的简体文本排序，保存语言标签仍为 `zh-CN` 等宿主支持值。

手动上传默认“自动识别”，旧 `default_language` 不再作为语言兜底。未知或过短文本会要求用户选择语言后再上传；明确指定语言时按用户选择。旧默认语言设置从配置页隐藏，工作台提供自动识别及手动语言选择。

失败计入结果且不记录密钥或临时下载链接。只有宿主确认写入后才计入保存数量。繁简转换随插件内置 opencc-python-reimplemented 0.1.7 及词典，无需宿主安装依赖或运行时联网下载；许可证及来源见 `_vendor/`。仅转换自动下载保存的中文字幕，不自动处理已有文件或手动上传。自动处理仅使用在线字幕源，旧配置中的字幕策略和联动开关不再参与执行。

测试全部使用模拟下载与文件写入接口；真实服务配额、验证码及站点页面变化仍可能导致下载失败。


### 媒体列表数据来源

页面通过 SDK `context.media_files.recorded_catalog` 查询同步产物和本地整理成功产物，
使用统一的文件记录结构与数据库分页。插件不直接访问数据库或主项目内部模块。
选中媒体后，通过 `recorded_detail` 精确读取该文件的元数据，并通过现有 `subtitles`
能力加载字幕。列表本身不扫描磁盘，也不提前读取所有媒体的字幕。

此版本需要主项目提供上述通用 SDK 能力；不使用目录全扫描作为旧主程序的降级路径。
原有自动事件处理、字幕写入和调轴行为保持不变。
