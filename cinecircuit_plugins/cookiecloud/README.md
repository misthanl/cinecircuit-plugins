# CookieCloud 站点同步

## 支持功能

- 接收浏览器 CookieCloud 扩展上传的加密 Cookie 快照。
- 验证匹配的 PT 站点并更新站点 Cookie。
- 支持定时检查、保存配置后执行一次，以及结果通知。

## 使用方法

1. 在浏览器中安装 CookieCloud 扩展。
2. 在主程序安装并启用插件，填写用户 KEY 和端到端加密密码。
3. 浏览器扩展填写相同的 KEY、密码，服务地址填写主程序地址加 `/plugin-public/cookiecloud`。
4. 在浏览器中登录需要同步的站点，并上传 Cookie。
5. 设置插件执行周期，或选择保存后执行一次，查看站点检查结果。

## 注意事项

- 浏览器需要能够访问填写的服务地址，远程使用时建议通过 HTTPS 连接。
- 浏览器上传后，站点验证和更新按插件的执行安排进行。
- Cookie 失效时，重新登录对应站点并上传新的快照。
- 请妥善保管 KEY、加密密码和浏览器账号。
