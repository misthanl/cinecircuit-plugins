# 转移做种

要求 CineCircuit v1.3.5 或更新版本，通过通用 `torrents` SDK 操作 qBittorrent / Transmission。自动任务默认关闭；配置不同的源、目标下载器后可预览，再手动执行或设置周期。

可设置必须全部包含的转移标签、不转移标签、无标签任务、分类和排除目录。带“刷流”标签的来源任务始终排除。保存目录映射每行填写一组“源目录#目标目录”，例如 `/downloads#/media`，留空沿用原路径；匹配目录边界并优先使用最长匹配。已有的两列映射配置仍可读取。两端必须能够访问相同的数据文件，插件不会复制或移动文件。

优先从下载器导出种子；不支持导出时，源种子目录必须能被 CC 容器读取。提交时保持暂停，完成校验后才按配置启动。跳过校验只对 qB 生效。删除源任务必须等目标确认完整，且始终保留文件；目标重复的处理由独立开关控制。

校验队列保存于插件自己的历史记录，重启后继续检查。操作前核对 hash、下载器和添加时间，避免操作重新添加的同 hash 任务。统计页面使用 CC 现有组件。上游参考与移植范围见 [SOURCES.md](SOURCES.md)。
