# 跨网盘复制

通过宿主 Storage SDK v2 组合源、目标能力。首批适配 115、123、光鸭，可选择九种源目标组合，包括同类型的不同账号。网盘是否命中秒传取决于目标端和可用的校验材料。

## 手动选择复制

侧边栏菜单进入双栏文件工作区：左侧选择源网盘并勾选文件、文件夹，右侧进入目标目录，然后选择复制策略并提交。文件夹保留名称及内部层级。切换源目录会清除勾选，仅提交当前目录中选中的内容。

手动批次独立持久化，不修改自动规则，未配置自动复制时也能使用。后台每分钟处理队列，每轮最多处理 20 个文件，页面在批次运行期间自动刷新进度；失败批次可查看原因并核对重试。提交重试沿用批次标识，避免网络响应丢失后重复入队。

## 使用

1. 选择源网盘、源目录、目的网盘和目的目录；切换账号会重置对应目录。
2. 选择复制策略及复制后的处理方式。
3. 手动全量可在统计页点击“重新扫描”。定时全量默认关闭，选中后设置每隔多少分钟执行，默认 60 分钟，等待一个间隔后首次执行。
4. 源网盘支持变更事件时提供“生活事件”选项。目前 115 支持，123、光鸭只提供手动全量和定时全量。触发方式为单选，定时全量与生活事件互斥。
5. 仅开启生活事件不会执行首次全量，只处理开启后捕获的事件。需要历史文件时手动扫描或开启定时全量。
6. 统计页提供真实总计、搜索、处理结果/复制方式筛选、文件级分页、详情和核对重试。源网盘和目的网盘分别显示。

### 策略

| 选择 | 文件正文读取 | 目标正文上传 |
| --- | --- | --- |
| 仅使用已有校验信息 | 不允许 | 不允许 |
| 允许读取源文件验证秒传 | 允许范围读取，必要时完整下载到临时目录 | 不允许 |
| 允许服务器中转上传 | 允许 | 秒传不命中时允许 |

SHA-1、MD5、GCID/CID 不是同一种校验材料。115 的验证可能要求读取源文件范围；跨算法复制可能需要完整读取源文件。选择“仅使用已有校验信息”时，材料不足会跳过，不会擅自读文件或中转。

单文件临时空间上限限制完整下载；临时文件在操作结束后清理。暂停在当前文件处理结束后生效。请求超时或服务重启留下的“结果待确认”不会自动重复提交；先检查网盘，再使用“核对并重试”。

## 自动与恢复

- 不再默认每 24 小时补扫，旧的 `enabled` / `rescan_hours` 配置不再隐式开启自动复制。升级后请自行选择触发方式。
- 宿主每分钟检查触发条件，按用户指定分钟间隔发起全量；其他轮次只处理已排队的工作或已开启的生活事件。全量分页扫描，每轮最多复制 20 个文件，进度持久化。
- 手动扫描、定时全量和生活事件都不会自动删除源文件或目标文件。
- 生活事件通过宿主独立消费游标读取，不推进整理／同步的游标；目录事件只扫描受影响的子目录，不重扫整个源目录。
- 整理、同步、转存完成通知不再单独触发复制，避免绕过用户选择的全量／生活事件方式。
- 暂停在当前文件处理完成后生效，继续时复用已保存进度。重新扫描会解除暂停，并在已有批次结束后执行。
- 已完成内容去重。不同内容同名文件沿用稳定后缀；不确定结果不会自动重传。
- 未配置账号时统计页显示正常空态，修改类操作保持不可用。

复制完成后可选择仅复制、交接整理或同步本批。复制和后续交接分别持久化，交接失败不重新复制。整理要求目标账号已有可用整理设置；同步要求目标父目录命中现有映射。`disabled`、`unmapped` 表示复制成功但目标自动化未配置。

## 边界

插件只导入公开插件契约与权限常量，使用宿主的 `storage`、`state` SDK。插件不保存 Cookie、Token、直链或上传凭据，不读取宿主业务表。

宿主负责受控读取、复制原语、权限审计及现有工作流交接；各网盘适配器解释各自的秒传协议。新网盘实现 `CopySource` / `CopyTarget` 并声明能力即可参与组合，不需要按网盘对新增业务分支。

## 验证范围

本地测试覆盖九种方向的统一调度与去重、禁止隐式中转、源版本改变、同名冲突、结果不确定后的恢复、交接失败重试和真实数据库中的资产登记。网盘接口测试使用模拟响应。

2026-09-14 已在 NAS 上验证三个网盘的九方向小文件复制、重复执行去重、115 不同账号秒传、插件持久化执行与批次事件触发，以及三个网盘的整理移动、资产 STRM 同步和播放分段内容校验。测试包含预先上传到三个网盘的 64 KiB 样本，不能据此保证任意文件都会命中秒传；跨校验类型可能需要读取完整源文件。大文件分片和全新分享转存尚未纳入本轮实盘验证。安装包需要与本次宿主 SDK 更新配套使用。
