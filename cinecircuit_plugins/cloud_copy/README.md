# 跨网盘复制

## 支持功能

- 在不同网盘账号之间复制文件或文件夹，保留文件夹层级。
- 支持已有校验信息秒传、读取文件验证秒传和服务器中转上传。
- 提供手动选择复制、手动全量、定时全量及支持来源的生活事件触发。
- 查看复制记录和进度，暂停、继续、核对并重试未完成任务。
- 复制完成后可选择仅复制、交接整理或同步本批文件。

### 秒传能力对照

行是源网盘，列是目标网盘。下表按当前可取得的文件校验信息标注；实际命中由目标网盘判断。

| 源网盘 ↓ / 目标网盘 → | 115网盘 | 123网盘 | 光鸭云盘 | 夸克网盘 |
|---|:---:|:---:|:---:|:---:|
| **115网盘** | ✅ | 🟡 | 🔵 | 🔵 |
| **123网盘** | 🔵 | ✅ | ✅ | 🔵 |
| **光鸭云盘** | 🔵 | 🔵 | 🔵 | 🔵 |
| **夸克网盘** | 🟡 | 🟡 | 🟡 | 🔵 |

- ✅ **可直接尝试秒传**：使用已有校验信息，部分目标需要读取少量文件片段。
- 🟡 **有条件支持**：取决于账号接入方式，见下表。
- 🔵 **需下载校验后尝试秒传**：现有校验信息不足，需要先读取完整文件。

| 有条件的组合 | 条件 |
|---|---|
| 115 → 123 | 目标账号支持开放平台 SHA-1 秒传 |
| 夸克 → 115 | 源账号使用 Open 接入，能提供 SHA-1 |
| 夸克 → 123 | Cookie 接入可用 MD5；Open 接入需目标支持 SHA-1 秒传 |
| 夸克 → 光鸭 | 源账号使用 Cookie 接入，能提供 MD5 |

光鸭作为源时，目前取得的秒传材料需要补齐；夸克作为目标时需要 MD5 和 SHA-1。同类型的不同账号也按表中条件处理。

## 使用方法

### 手动选择文件

1. 在主程序添加源、目标网盘账号，确认连接正常。
2. 安装并启用插件，开启侧边菜单，进入“跨网盘复制”。
3. 选择源网盘，进入目录并勾选文件或文件夹。
4. 选择目标网盘，进入接收文件的目录。
5. 设置复制策略、单文件临时空间上限和复制完成后的处理方式，点击复制。
6. 在“复制记录”中查看批次进度，遇到失败或待确认结果时核对后重试。

### 设置自动复制

1. 在插件配置中选择源网盘、源目录、目标网盘和目标目录。
2. 从下列触发方式中选择一种，设置策略后保存。

| 触发方式 | 使用方式 |
|---|---|
| 手动全量 | 在统计页点击“重新扫描”，处理配置的源目录 |
| 定时全量 | 设置执行间隔，默认 60 分钟，保存后等待一个间隔开始首次执行 |
| 生活事件 | 根据源网盘的新变更处理文件，可用性以所选账号提供的选项为准 |

生活事件适合持续跟踪新变更；需要复制已有文件时，可先执行手动全量。

### 选择复制策略

| 策略 | 处理方式 |
|---|---|
| 仅使用已有校验信息 | 使用现有材料尝试秒传；材料不足或未命中时跳过 |
| 允许读取源文件验证秒传 | 按需读取片段或完整下载，补齐校验后尝试秒传；未命中时跳过 |
| 允许服务器中转上传 | 优先尝试秒传，未命中时通过服务器下载并上传 |

115 等目标的片段校验需要选择允许读取源文件的策略。表中的 🔵 组合需要允许完整文件读取，并提供足够的临时空间。

## 注意事项

- 秒传支持表示具备尝试条件，实际命中取决于目标网盘是否接受该文件的校验信息。
- 服务器中转会占用网络带宽和临时磁盘空间；单文件临时空间上限默认 10 GiB，请结合文件大小设置。
- 复制保留源文件；目标出现不同内容的同名文件时会使用后缀区分。
- 切换源目录会清除当前勾选，请在提交前核对所选内容和目标位置。
- 暂停在当前文件处理结束后生效，继续时使用已保存进度。
- 遇到“结果待确认”，先核对目标网盘中的文件，再使用核对重试功能。
- 选择交接整理时，目标账号需要开启并配置整理；选择同步本批文件时，目标目录需要匹配已启用的同步映射。请先确认相应开关和规则。
