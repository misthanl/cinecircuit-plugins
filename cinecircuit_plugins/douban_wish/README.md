# 豆瓣想看

填写豆瓣用户ID（多个以逗号或换行分隔），按公开动态RSS同步“想看”记录。默认每30分钟运行，可设置执行周期，也可使用现有插件菜单立即运行。默认同步近7天。

只对明确匹配豆瓣条目ID的影视进行识别，再通过订阅前检查跳过已有订阅和完整入库作品。识别不明确、媒体库查询不完整时保留重试，不猜测影片或剧集类型。多用户同一作品只处理一次。

配置、启停和立即运行沿用标准插件界面。统计页使用现有影视榜单的海报卡片、累计指标、最近执行明细和分页布局。可读取停用期间的历史统计；清理历史仅影响本插件，不删除已有订阅。

限制：只读取豆瓣公开RSS实际返回的条目，无法读取私密动态、补齐RSS未返回的旧记录或绕过访问限制。账号读取失败会记入最近执行明细，其他账号继续处理。

初始版本：1.0.0。
