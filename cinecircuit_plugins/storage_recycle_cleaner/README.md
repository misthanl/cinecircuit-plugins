# 网盘回收站清理

## 支持功能

- 清空所选网盘账号的回收站，释放存储空间。
- 支持定时清理、结果通知及回收站安全密钥。
- 账号选择栏显示当前支持回收站清理的网盘。

## 使用方法

1. 在主程序中添加网盘账号并确认连接正常。
2. 安装并启用插件，授予回收站清理权限。
3. 选择网盘；账号设置了回收站密码保护时，填写相应安全密钥。
4. 核对账号后勾选永久清空确认，设置执行周期并保存。
5. 通过执行记录或通知确认清理结果。

## 注意事项

- 清理范围是整个账号的回收站，永久清空后无法恢复，请谨慎确认。
- 定时清理默认关闭，默认周期为每天 03:00。
- 115 回收站安全密钥为六位数字，启用密码保护时需要填写。
- 遇到超时或失败，先到网盘检查回收站状态，再决定是否重新执行。
