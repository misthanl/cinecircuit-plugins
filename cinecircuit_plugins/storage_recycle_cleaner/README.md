# 网盘回收站清理

通过宿主 SDK 的通用存储能力，定时或手动永久清空指定账号的回收站。目前由 115 存储适配器提供支持；后续网盘适配器实现相同能力即可接入。

- 从存储设置选择支持 `recycle_bin_clear` 的已启用存储，不单独保存 Cookie。
- 默认关闭定时清理，默认周期每天 03:00；必须选择存储并确认永久清空。
- 清理范围为整个网盘账号的回收站，不受存储挂载目录限制，无法恢复。
- 115 安全密钥为六位数字，使用秘密配置字段保存。未开启回收站密码保护时可留空。
- 清理需要独立危险权限 `storage:clear_recycle_bin`，仅读取存储权限不能清理。
- 超时或响应失败不会由插件自动重试，应先核实回收站状态。

需要包含通用存储回收站 SDK 能力的宿主版本。仅替换插件包不能为旧宿主添加此能力。
