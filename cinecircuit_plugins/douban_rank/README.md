# 豆瓣榜追更

## 支持功能

- 跟踪豆瓣电影、电视剧及综艺榜单。
- 按最低评分筛选作品，匹配媒体后添加订阅。
- 支持自定义榜单地址、RSSHub 地址、代理和定时执行。
- 记录处理历史，查看榜单处理和订阅结果。

## 使用方法

1. 在主程序中配置订阅所需的站点、下载器和资源规则。
2. 安装并启用插件，选择需要跟踪的榜单。
3. 设置最低评分及执行周期；使用自定义来源时填写对应地址。
4. 按网络情况选择系统代理，保存配置。
5. 查看插件记录和订阅列表，确认新增作品。

## 注意事项

- 榜单可用性受豆瓣、RSSHub 和自定义来源的访问状态影响。
- 订阅后的资源搜索与下载遵循主程序的订阅规则。
- 清理历史后，下一次执行会重新评估榜单中的作品。
