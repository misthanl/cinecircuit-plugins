# 探索菜单扩展

将腾讯视频、优酷、爱奇艺、芒果 TV 的电影及电视剧频道片库显示在原有“探索”数据源选项中，不新增左侧菜单。

安装后将插件标记为可信、授予“媒体发现”权限并启用。插件属于“媒体工具”，点击卡片直接打开配置，不提供统计页面或立即运行入口。配置使用主项目的标准表单，开关名称为腾讯视频、优酷、爱奇艺、芒果 TV。默认均开启；关闭单个平台仅隐藏该平台，全部关闭则不提供平台入口。禁用插件时所有入口移除。

每个平台旁边有一个顺序数字，数字越小，在探索页中越靠前。默认顺序数字为 1、2、3、4；相同数字保持默认先后，隐藏的平台不占显示位置。保存配置后重新进入探索即可看到调整后的顺序。

片库读取各平台网站使用的公开频道接口，保留原始标题、海报、简介、年份和顺序。按平台返回的条件提供类型、地区、年份、排序、资费及平台专属筛选，条件传给平台处理。支持继续下滑分页；分页游标按平台、媒体类型、完整筛选组合隔离，过期时需要重新加载第一页。

详情和订阅在点击时通过媒体发现 SDK 匹配 TMDB；已知年份必须一致，同名作品必须唯一，否则提示确认，不猜测 ID。未匹配作品仍保留在片库里，支持按标题搜索资源。需要主项目已配置可用的 TMDB 来源。分页结果缓存 10 分钟，响应有大小和时间限制；平台不可用时明确报错，不回退为搜索热榜。平台播放和会员登录不在本插件范围内。

匹配先检查名称、类型和年份；搜索结果缺少年份时补查 TMDB 详情。仍无法唯一确认时，通过 SDK 的 `media.assist_identity` 使用现有“媒体识别辅助”场景的开关和模型配置。AI 线索须经过元数据查询及详情核验，来源、类型、年份冲突或无法确认时仍需人工选择。此流程只在本插件四个平台点击作品时调用，原生 TMDB、豆瓣流程不变。

需要主项目支持 `explore_sources` 插件清单、`explore-sources` 扩展目录及 `media.assist_identity` 能力。旧版主项目缺少辅助能力时保留常规匹配及人工确认，不调用 AI。

插件初始版本为 1.0.0。
